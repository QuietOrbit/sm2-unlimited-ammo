[size=5][b]Unlimited Ammo[/b][/size]
Never run dry again. Choose your ammo mode at install, plus optional unlimited grenades.

[b]Current version:[/b] {version} — built for game build {game_build}

[size=4][b]Options[/b][/size]
[list]
[*][b]Unlimited Reserve[/b] — your reserve ammo never runs out. You still reload.
[*][b]No Reload[/b] — bottomless magazines. You never reload.
[*][b]Unlimited Grenades[/b] (optional add-on) — frag, krak and shock grenades never run out.
[/list]
Covers every player weapon in Campaign and Operations/Siege, including weapon perk variants like the underbarrel grenade launcher. [b]PvP is not affected.[/b]

[size=4][b]Why another infinite ammo mod?[/b][/size]
Older ammo mods ship a copy of the game's weapon file from whatever patch they were made for, so they break or crash when the game updates. This mod is generated straight from the current game files, and it uses the infinite-ammo switches the game already has (the same ones enemies use) instead of huge ammo numbers. When a patch drops, it's rebuilt in seconds.

[size=4][b]Installation[/b][/size]
[b]Vortex / MO2:[/b] Install the main file. A menu will ask which options you want.
[b]Manual:[/b] See the README inside the download. Copy one ammo .pak (plus the optional grenades .pak) into [i]client_pc\root\mods[/i] and add each one to [i]pak_config.yaml[/i].

[size=4][b]After a game update[/b][/size]
If the game crashes after a patch, disable the mod until I upload a new version. If you can't wait, grab the optional [b]Patcher[/b] file: double-click [i]Run_Patcher.bat[/i] and it rebuilds the mod from your own game files (needs Python 3.10+).

[size=4][b]Compatibility[/b][/size]
Conflicts with any mod that changes these files (whichever loads last wins):
[list]
[*]ssl/weapons/creator/firearm_library_pve.sso
[*]ssl/weapons/creator/customization/firearm_modificators_library.sso
[*]ssl/abilities/ability_library.sso (grenades only)
[/list]
Known conflicts: [b]Astartes Overhaul[/b], [b]Primarch – Power Fantasy[/b], and other infinite-ammo mods.

[size=4][b]Co-op[/b][/size]
Works best solo or as host. Please don't use it in public lobbies with strangers.
