[size=5][b]Unlimited Ammo[/b][/size]

[b]Works on patch {game_version}, the current version of Space Marine 2.[/b]

I hope it keeps working through future game updates. If an update breaks it, I will post a fixed version here as soon as I can.

[size=4][b]Options[/b][/size]
[list]
[*][b]Unlimited Reserve.[/b] Reserve ammo never runs out. Reloading works as normal.
[*][b]No Reload.[/b] Magazines never empty, so reloading is never needed.
[*][b]No overheating.[/b] Included with both ammo modes. Heat-based weapons never build heat, so they never overheat or lock up.
[*][b]Unlimited Grenades.[/b] An optional add-on. Frag, krak, and shock grenades refill about half a second after each throw.
[/list]
The options apply to every player weapon in PvE modes, including weapon perk variants such as the underbarrel grenade launcher. PvP is not affected.

[size=4][b]Installation[/b][/size]
With Vortex or Mod Organizer 2:
[list=1]
[*]Install the main file.
[*]Choose an ammo mode in the installer menu.
[*]Select Unlimited Grenades as well if wanted.
[/list]
Manual installation steps are in the README included in the download.

[size=4][b]After a game update[/b][/size]
A game update can change the files this mod replaces. If the game crashes after an update, disable the mod until a new version is posted here. The optional Patcher file rebuilds the mod from the installed game files in a few seconds. It requires Python 3.10 or newer.

[size=4][b]Compatibility[/b][/size]
This mod conflicts with any mod that replaces the same game files. When two mods replace the same file, the one listed higher in pak_config.yaml takes effect. Known conflicts are Primarch – Power Fantasy, Astartes Overhaul, and other infinite ammo mods.

The files this mod replaces are listed below.
[list]
[*]ssl/weapons/creator/firearm_library_pve.sso
[*]ssl/weapons/creator/customization/firearm_modificators_library.sso
[*]ssl/abilities/ability_library.sso, only with Unlimited Grenades
[/list]

[size=4][b]Astartes Overhaul[/b][/size]
Astartes Overhaul replaces the same weapon files, so the two mods conflict. There is no compatible version at the moment.

[size=4][b]Co-op[/b][/size]
The mod is intended for solo play and private co-op. Public lobbies with strangers are not an appropriate place to use it.
